# Signatures mail interactives Keza

Une signature par associé (Gabriel, Kevin, Zinedine), à coller dans Infomaniak Mail.

- `signature-<prénom>.html` : la signature. L'ouvrir dans Safari, Cmd + A, Cmd + C, puis
  Infomaniak Mail → Paramètres → Signatures → coller.
- `img/` : logo « Keza agency » (vrai logo, police Clother) et icônes. Les signatures les chargent
  depuis ce dépôt : **il doit rester public**, et ces fichiers ne doivent pas être renommés ni déplacés.
- `signatures-keza.png` : aperçu des trois.

Facebook et LinkedIn : icônes prêtes dans `img/`, à ajouter quand les pages existeront.
